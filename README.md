# Image Metadata Cleaner

ブラウザ内で画像のメタデータ（EXIF・位置情報・撮影機種など）を削除する静的Webツールです。
ビルド工程や外部ライブラリは不要で、`index.html` 1枚で動作します。

## GitHub Pagesで公開

1. このリポジトリの `index.html` と `README.md` をルートに置きます。
2. **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、Branch を `main`、フォルダを `/(root)` にして **Save** を押します。
4. Pages画面に表示されるURLで利用できます。

## 使い方

1. 画像をドラッグ＆ドロップ（またはクリックして選択）します。
2. 必要なら「写真の向きだけは残す」を設定します（初期値はオン）。
3. **選択画像を一括処理** を押します。
4. 1枚ならそのファイル、複数枚なら `cleaned_images.zip` が保存されます。各行の「保存」から個別にも保存できます。

処理結果の各行には、除去した項目（EXIF / XMP / コメント など）が表示されます。
位置情報（GPS）が含まれていた画像には警告マークが付きます。

## 対応形式

形式は拡張子ではなく**ファイルの中身**で判定します。

| 形式 | 除去するもの | 保持するもの |
|---|---|---|
| JPEG | EXIF、XMP、IPTC/Photoshop、コメント、MPF、C2PA等のAPP領域、終端後の付加データ | 画像データ、ICCプロファイル、Adobe色変換情報 |
| PNG | テキスト（tEXt/zTXt/iTXt、XMP含む）、EXIF、更新日時、その他の補助チャンク、終端後の付加データ | 画像データ、ICC・ガンマ等の色情報、透過、APNGのアニメーション |
| WebP | EXIF、XMP、不明なチャンク、終端後の付加データ | 画像データ、ICCプロファイル、透過、アニメーション |
| GIF | コメント、XMP、不明なアプリケーション拡張、終端後の付加データ | 画像データ、ループ・遅延などのアニメーション情報 |

HEIC / AVIF / TIFF / BMP などは未対応です（その旨をエラー表示します）。

## 写真の向き（Orientation）について

EXIFを丸ごと消すと、スマホで縦に撮った写真が横向きで表示されることがあります。
そのため初期設定では、EXIFのうち**向き情報だけ**を最小のEXIF（26バイト）として残します。
撮影日時・機種・位置情報などは残りません。完全にEXIFを無くしたい場合はチェックを外してください。

## プライバシーと処理

- 画像処理はすべて利用者のブラウザ内で実行し、画像をサーバーへ送信しません。
- ページには `Content-Security-Policy` を設定しており、ブラウザ側でも外部通信（`connect-src 'none'`）を禁止しています。
- 画像は再圧縮せず、メタデータ部分だけを取り除きます。画質は変わりません。
- 処理後、出力をもう一度同じ処理にかけて結果が変わらないこと（除去対象が残っていないこと）を自動で確認します。

## 注意

すべての独自形式・未知のメタデータを完全に検出できるとは限りません。
重要な画像は、元画像を保管したうえで、処理後の画像を別のツールでも確認してください。
